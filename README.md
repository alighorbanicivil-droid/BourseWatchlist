# رتبه‌بندی نمادهای بورسی از کانال‌های تلگرام

وب‌اپ فارسی که پست‌های «صورت مالی» یک یا چند **کانال عمومی تلگرام** را می‌خواند و نمادهای هر صنعت را با امتیاز قابل توضیح رتبه‌بندی می‌کند. هر نمادی که گزارشش در بازه‌ی انتخابی منتشر شده وارد رتبه‌بندی می‌شود (سقف ۱۰ تایی ندارد). بدون وابستگی خارجی (فقط Node.js ≥ 18).

## امکانات
- **چند کانال همزمان** و شمارش «تأیید کانال‌ها» کنار هر نماد (تأیید = کانال گزارش مالی آن نماد را منتشر یا آن را با هشتگ ذکر کرده؛ توصیه‌ی خرید نیست)
- **بازه‌ی زمانی با تاریخ شمسی:** با عوض‌کردن «از/تا تاریخ» همان لحظه و بدون سرور فقط نمادهای منتشرشده در آن بازه (و میانه‌ی P/E همان نمادها) محاسبه می‌شود. داده‌ی خودکار ۹۰ روز اخیر را نگه می‌دارد (`days` در `config.json`)
- **P/E نسبت به میانه‌ی صنعت خودش** فقط از نمادهای همان بازه (صنعت با کمتر از ۳ نماد: میانه‌ی کل نمادهای بازه)
- **دلیل رتبه** زیر هر نماد + تاریخ گزارش (با برچسب «قدیمی» بعد از ۱۰ روز)
- **قیمت فعلی** کنار قیمت گزارش (اختیاری؛ پایین را ببین)
- **به‌روزرسانی خودکار روزانه** با GitHub Actions و انتشار روی GitHub Pages
- **سابقه عملکرد:** هر روز یک عکس فوری از رتبه‌بندی ذخیره می‌شود و تغییر قیمت نمادهای برتر تا امروز نشان داده می‌شود
- **چک‌لیست** هر صنعت، دکمه‌ی انتخاب/برداشتن همه، کشوی ۱۵ تکنیک حرفه‌ای و ساخت چک‌لیست شخصی (داخل همان کشو)
- **خروجی PDF** با گرافیک (دکمه‌ی «خروجی PDF» ⇢ در پنجره‌ی چاپ مرورگر «Save as PDF» را بزن)

## اجرا روی کامپیوتر
```bash
npm start          # http://localhost:3000  (دکمه‌ی «دریافت اکنون» فقط با سرور کار می‌کند)
npm run update     # یک بار دیتا را از کانال‌های config.json بگیر و data را بنویس
npm test           # تست‌ها
```

## انتشار روی GitHub (ساختار root)
1. یک ریپوی **Public** بساز و **محتویات** این پوشه را (از جمله `.github` و `.nojekyll`) در ریشه‌ی شاخه‌ی `main` آپلود کن.
2. Settings ⇠ Pages ⇠ Source = **Deploy from a branch** ⇠ Branch = `main` و پوشه = **`/ (root)`** ⇠ Save.
3. Settings ⇠ Actions ⇠ General ⇠ Workflow permissions = **Read and write permissions** ⇠ Save.
4. `config.json` را با کانال‌ها و تعداد روزهای بازه تنظیم کن:
   ```json
   { "channels": ["FocusWatchList", "کانال_دوم"], "days": 90, "maxPages": 120, "prices": true }
   ```
5. تب Actions ⇠ `update-data` ⇠ Run workflow. از آن به بعد هر روز حدود ۰۸:۰۰ تهران داده گرفته و در `data/` ذخیره می‌شود.
6. آدرس سایت: `https://USERNAME.github.io/REPO/`

`days` را بزرگ‌تر کنی باید `maxPages` را هم بیشتر کنی (هر صفحه حدود ۲۰ پست)؛ اگر به سقف برسد هشدار چاپ می‌شود. بدون تاریخ‌های «بازه»، داده‌ی نمونه‌ی اولیه (بدون تاریخ گزارش) نمایش داده می‌شود و با انتخاب بازه کنار می‌رود.

## دکمه‌ی «دریافت اکنون» روی GitHub Pages
مرورگر اجازه‌ی خواندن مستقیم تلگرام را ندارد (CORS)، پس دکمه به‌ترتیب این‌ها را امتحان می‌کند:
1. اگر برنامه با `npm start` اجرا شده باشد، از سرور خودش می‌خواند (پایدارترین حالت و با قیمت فعلی).
2. وگرنه از چند **پراکسی عمومی** (corsproxy.io، allorigins، codetabs) استفاده می‌کند. این سرویس‌ها از سمت من تست نشده‌اند، ممکن است کند یا محدود باشند و از ایران گاهی بدون VPN باز نمی‌شوند.
3. اگر هیچ‌کدام جواب نداد، **پراکسی شخصی رایگان** بساز: در cloudflare.com ⇠ Workers & Pages ⇠ Create ⇠ Worker، محتوای `tools/cloudflare-worker.js` را جایگزین کد کن و Deploy بزن. آدرس را با `?url=` تمام کن (مثلاً `https://my-proxy.USER.workers.dev/?url=`) و در اپ داخل «پراکسی شخصی» بگذار؛ در مرورگر ذخیره می‌شود. این پراکسی فقط صفحه‌های عمومی `t.me/s/…` را عبور می‌دهد.

نتیجه‌ی دریافت فقط در مرورگر همان دستگاه ذخیره می‌شود؛ داده‌ی روزانه‌ی GitHub و تاریخچه تغییر نمی‌کنند. قیمت فعلی در این حالت از آخرین داده‌ی ذخیره‌شده می‌آید.

## نصب به‌عنوان اپ (PWA)
سایت manifest، آیکون و service worker دارد و روی HTTPS (مثل GitHub Pages) قابل نصب است. روی اندروید در **Chrome** منوی ⋮ ⇠ «Install app» یا «Add to Home screen»؛ روی آیفون در **Safari** دکمه‌ی Share ⇠ «Add to Home Screen». داخل مرورگر تلگرام/اینستاگرام گزینه‌ی نصب نیست؛ لینک را در Chrome یا Safari باز کن. بعد از نصب، آخرین داده‌ی دیده‌شده آفلاین هم نمایش داده می‌شود. نصب با `http://` معمولی (غیر از localhost) ممکن نیست.

## قیمت فعلی؛ مهم
`lib/prices.js` قیمت را از TSETMC (نسخه‌ی قدیمی) می‌گیرد، ولی:
- فرمت پاسخ‌ها از روی حافظه نوشته شده و **با سرویس واقعی تست نشده**. هر قیمت با قیمت گزارش مقایسه و اگر خارج از ۰.۳ تا ۳ برابر بود نادیده گرفته می‌شود.
- TSETMC ممکن است درخواست از سرورهای خارج ایران (از جمله GitHub Actions) را مسدود کند. اگر قیمتی نیامد، اپ بدون آن کار می‌کند و «سابقه عملکرد» به قیمت گزارش‌ها برمی‌گردد و هشدار می‌دهد.
- راه‌حل: `npm run update` را روی کامپیوتر/سروری که به TSETMC دسترسی دارد اجرا کن، یا `fetchOne` را در همین فایل با منبع دلخواه عوض کن. خاموش‌کردن: `PRICE_SOURCE=off`.

## ساختار
- `index.html`, `app.js` رابط کاربری (همان چیزی که Pages نشان می‌دهد) و `data/` داده‌ی تولیدشده
- `scoring.js` امتیازدهی و دلیل رتبه (هم در مرورگر، هم در Node)
- `jalali.js` تبدیل تاریخ شمسی
- `parser.js`, `industries.js`, `fetcher.js` پارس پست‌ها، نقشه‌ی صنعت و دریافت/خزش کانال‌ها (مشترک بین مرورگر و Node؛ `industries.js` را ویرایش کن)
- `tools/cloudflare-worker.js` پراکسی شخصی برای دکمه‌ی «دریافت اکنون»
- `manifest.webmanifest`, `sw.js`, `icon-*.png` برای نصب به‌عنوان اپ
- `merge.js` فیلتر بازه، انتخاب جدیدترین گزارش هر نماد و شمارش کانال‌های تأییدکننده (مشترک بین سرور و مرورگر)
- `lib/` دریافت سمت سرور (کش)، قیمت و ساخت اسنپ‌شات
- `scripts/update.js` به‌روزرسانی خودکار؛ `.github/workflows/update.yml` زمان‌بندی
- `server.js` سرور محلی (`npm start`)؛ فقط فایل‌های رابط و `data/` را سرو می‌کند
- `test/` تست‌ها، از جمله با متن پست‌های واقعی کانال

## محدودیت‌ها
- فقط کانال‌های عمومی با پیش‌نمایش وب (`t.me/s/…`) و فقط پست‌های «صورت مالی شش/نه ماهه» با قالب کانال Watch List؛ برای قالب دیگر، عبارت‌ها را در `lib/parser.js` تنظیم کن.
- «تأیید کانال» فقط ذکر نماد است، نه تحلیل مثبت.
- اعداد از کانال گرفته می‌شود و توصیه‌ی مالی نیست؛ با کدال تطبیق بده.
